# SD_CARD

The test build, ready to copy to the root of the SD card. `tools/make_sd.py` fills this folder. Nothing but
this file is in git: the game's files are yours and stay on your machine.

```
switch/prey/
  prey.nro       the game
  base/          your copy of Prey's .pk4 files
  shaders/       the game's shaders, compiled from your copy
```
